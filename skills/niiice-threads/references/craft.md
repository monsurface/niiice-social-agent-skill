# Threads 改寫判準

以本次 MCP brief 與使用者要求為準。以下整理本機改寫流程可攜的判斷方式，例子及品牌內容由客戶自己的資料提供。

先決定這篇的目的：漲粉文要展示有根據的專業判斷；流量文要讓讀者容易理解或參與；品牌文要讓讀者認識這個人／品牌的立場。整篇只用一條主線。

短稿選一個結構，跟著原文最吸引人的事實走，不混合多套開場及收尾。專業長稿保留必要的機制、例子與限制，改用短句及串文承載，不為了變短刪掉專業內容。原文含兩個互不相關的題目時，可建議分成兩篇。

每一段都核對六件事：

| 面向 | 判斷 |
|---|---|
| 開場 | 前兩句是否呈現最吸引人的具體事實或轉折？ |
| 收尾 | 是否從前文自然長出來，有結論或真實後續？沒有真問題就不硬問。 |
| 互動 | 讀者是否有理由分享自己的情況？不捏造有人詢問，不硬釣留言。 |
| 真實 | 數字、時間、人名、經驗及見證都有素材支持嗎？ |
| 易讀 | 一句一個意思，手機可讀，段落留白，列點與字數依 brief。 |
| 品牌 | 是否符合客戶的聲音、專業與品牌立場，而非模仿其他人的人設？ |

少用抽象形容詞，用素材中真實的細節。學範例的段落節奏及語氣，不搬故事、口頭禪或個人遭遇。不要為了把六個面向都填滿而硬塞技巧。寫完自己核對，不需呼叫額外的付費評分。

原文沒有的事實直接說缺；不要以【待補】內容存成可發布的終稿。使用者指定篇數、長度、語氣及不改的段落時照辦。
